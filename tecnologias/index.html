Tecnologias

Estas son las tecnologías que se han utilizado para el desarrollo de GameShelf:

  • Documentación:

    • MkDocs + Zensical para la creación de la documentación.
    • DrawIO para el diseño de los diagramas.
    • Miro para el diseño de la interfaz.

  • Bases de Datos:

    • SQLite3 como base de datos relacional.

  • Testing

    • Pytest - Django para los tests de Django
    • Pytest - Cov añade la funcionalidad del porcentaje de codigo testeado
    • Pytest - Rich hace que al lanzar los test, se devuelva información más específica sobre estos

  • Frameworks:

    • Django para el desarrollo de la aplicación del lado del servidor con Python.
    • Vue para el desarollo del cliente web de la aplicación con TypeScript.

  • Securización:

    • JWT para la autenticación y autorización de usuarios mediante tokens seguros entre cliente y servidor.

  • Despliegue:

    • Docker para la creación de contenedores y despliegue del proyecto en diferentes entornos.

  • APIs externas:

    • IGDB API para obtener los videojuegos.
