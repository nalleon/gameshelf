# Mantenimiento y actualización

## Política de mantenimiento

El mantenimiento de la aplicación **Lumino** se basa en revisiones periódicas del sistema con el objetivo de garantizar su correcto funcionamiento y la corrección de posibles errores detectados tras su uso.

Las actualizaciones se realizarán de forma puntual cuando sea necesario:

- Corregir errores o fallos detectados.
- Mejorar el rendimiento o la seguridad de la aplicación.
- Adaptar el sistema a nuevos requisitos o mejoras funcionales.

El soporte se centra en asegurar que las funcionalidades principales sigan operativas y que la plataforma pueda utilizarse sin incidencias graves.

---

## Changelog

El proyecto mantiene un registro de cambios que permite llevar un control de las mejoras y modificaciones realizadas a lo largo del desarrollo. Este registro facilita el seguimiento de la evolución del sistema y ayuda a identificar qué cambios se han introducido en cada versión.

Entre los cambios más relevantes se incluyen:

- Implementación de nuevas funcionalidades.
- Corrección de errores detectados durante las pruebas.
- Mejoras en la estructura del código y la organización del proyecto.
- Actualizaciones relacionadas con la documentación.

> Puede acceder al siguiente enlace para consultarlo en detalle: [changelog](https://github.com/nalleon/lumino/blob/main/CHANGELOG.MD)

## Plan de escalabilidad

La aplicación **Lumino** está diseñada para permitir su crecimiento tanto en número de usuarios como en funcionalidades. Algunas posibles mejoras para soportar una mayor carga o ampliar el sistema son:

- Sustitución de la base de datos actual por un sistema más robusto en entornos con mayor volumen de datos.
- Optimización del uso de tareas asíncronas para procesos costosos.
- Despliegue en entornos con balanceo de carga para soportar más usuarios simultáneos.
