# Conclusiones y futuro

## Estado actual del proyecto

El proyecto **Lumino** se encuentra en un estado funcional y estable, cumpliendo con los objetivos y requisitos definidos inicialmente. Se han implementado las funcionalidades principales de la plataforma, es decir, la gestión de usuarios, módulos formativos, matriculaciones y calificaciones, así como la generación de certificados.

Además, el proyecto cuenta con una documentación clara y estructurada, pruebas automatizadas y una base sólida que permite su mantenimiento y evolución futura.

---

## Futuras actualizaciones

De cara a futuras versiones, se plantean posibles mejoras y ampliaciones del sistema, entre las que se incluyen:

- Incorporación de nuevas funcionalidades orientadas a mejorar la experiencia de usuario.
- Optimización del rendimiento en entornos con mayor número de usuarios.
- Mejora de la seguridad y del control de accesos.
- Ampliación de la documentación con guías más detalladas.
- Integración de nuevas herramientas o servicios que faciliten la gestión y el despliegue.

---

## Lecciones aprendidas

Durante el desarrollo de **Lumino**, se han reforzado los siguientes conocimientos:

- Importancia de una buena planificación inicial y definición clara de requisitos.
- Valor del uso de frameworks y herramientas que facilitan el desarrollo y el mantenimiento.
- Necesidad de realizar pruebas de forma continua para detectar errores de manera temprana.
- Relevancia de una estructura de código clara y una documentación adecuada.

> Esto servirá como base para afrontar futuros proyectos de manera más eficiente y organizada.
